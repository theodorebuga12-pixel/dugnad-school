DUGNAD SCHOOL WEBSITE
=====================
Open index.html in any web browser to view the site (internet is needed only for the Google fonts).

FOLDER CONTENTS
  index.html   The complete website (all pages/sections, styles and scripts)
  images/      Every photo, logo and illustration used on the site

HOW MESSAGES REACH THE SCHOOL
  All forms and email buttons open the visitor's email app with a message addressed
  to dugnaduganda@gmail.com. The visitor presses Send there.

TO REPLACE A PICTURE
  Save your new photo in the images folder with the same file name
  (for example images/hero.jpg) and refresh the page.

NOTES
  Pictures marked with a star in the site are illustrative, not photos taken at the school.

TO PUBLISH ONLINE
  Upload the whole dugnad-school folder to GitHub Pages
  or your school's web hosting. Keep index.html and the images folder together.

SENDING MESSAGES STRAIGHT TO THE SCHOOL (FORMSUBMIT, WORKS ON GITHUB PAGES)
  The Contact form and the Apply / Ask forms send the message online through FormSubmit
  (formsubmit.co), so the visitor does not need an email app.
  ONE-TIME ACTIVATION (required):
  1. Publish the site on GitHub Pages and open the live address (not the file on your computer).
  2. Send one test message from any form.
  3. Open the Gmail inbox dugnaduganda@gmail.com. FormSubmit sends an email titled
     "Activate Form". Open it (check Spam too) and click the Activate button.
  4. Send another test message. It now arrives in the inbox for every visitor.
  If online sending ever fails, the site opens the visitor's email app as a backup.
